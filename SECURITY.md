# Security Policy

Termirust stores SSH credentials, so we take vulnerabilities seriously.

## Reporting

Please **do not** open a public issue. Report privately via
[GitHub Security Advisories](../../security/advisories/new).

Include steps to reproduce, affected version and impact. We aim to acknowledge within
3 days and to ship a fix or mitigation within 30 days for confirmed issues.

## Scope

The vault encryption, key handling, SSH host key verification, the sync protocol and the
data sent to AI providers are all in scope. See [PRIVACY.md](PRIVACY.md) for what leaves the machine.
