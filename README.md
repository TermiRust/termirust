# Termirust 🦀

An open-source, local-first SSH client **written in Rust** with Tauri.
Lightweight, fast, works fully offline — no account required.
End-to-end encrypted sync and team features are the paid tier.

> Status: early development (milestone M0). Not usable yet.

## Documentation

Open [`docs/index.html`](docs/index.html) in a browser for the project overview,
architecture, requirements, roadmap and task board.

## Development

Requirements: Rust (see `rust-toolchain.toml`), Node.js 22, pnpm.

```sh
cargo test -p termirust-core
pnpm install
```
